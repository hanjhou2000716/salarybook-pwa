# 薪資簿 SalaryBook V1.2.1 OCR 候選版

繁體中文、本機優先的薪資紀錄 PWA，支援 Android 與桌面瀏覽器。程式部署到 GitHub Pages；薪資資料留在使用者目前裝置的 IndexedDB。

- 月份總覽：可切換收入組成圓環圖，以及實領、扣款與暫支薪分配圖。
- 歷史趨勢：依年份及公司篩選應發、實領、扣款折線；缺漏月份保留空白。
- 薪資紀錄：手動新增、修改、刪除、核對、原圖保存及修訂紀錄。
- 匯入薪資單：兩頁 JPG、PNG、PDF，本機 OCR 及人工確認。
- OCR 診斷：逐步追蹤影像、分格、數字、欄位及表單填值；可在本機執行虛構圖自檢、修復資源快取。
- 本機備份：支援密碼加密、還原預覽、合併與 CSV 匯出。
- 離線 PWA：Service Worker 預快取網站、PDF 引擎、OCR 模型。
- 手機安裝：Android Chrome 提供安裝提示或選單指引；iPhone Safari 提供「分享 → 加入主畫面」步驟。

## 本機啟動

需要 Node.js 24。

```powershell
npm ci
npm test
npm run build
npm run dev
```

開啟伺服器顯示的 localhost 網址。首次載入後等待離線資源就緒。不要直接打開 `index.html`，瀏覽器本機資料庫、PDF 與離線功能需要 localhost 或 HTTPS。

首頁可載入「虛構示範資料」試用；這些數字不屬於任何實際薪資紀錄。匯入自己的薪資單後，請逐項人工確認 OCR 結果。

## GitHub Pages 部署

1. 將此專案推送到 `hanjhou2000716/salarybook-pwa` 的 `main` 分支。
2. GitHub Actions 會執行核心檢查、建置 `dist/` 並部署 GitHub Pages。
3. Pages 設定使用 GitHub Actions。成功後網址為 `https://hanjhou2000716.github.io/salarybook-pwa/`。

此 repository 與 Pages 網站為公開內容。公開版本不包含個人薪資紀錄、原始薪資圖片、雇主名稱、OCR 原文或真實薪資驗收值。網站使用者的資料只存在其瀏覽器內。

## 圖表資料規則

收入圖以已確認紀錄的收入細項加總，必須與原單應發總額相符才顯示占比。現金流圖需滿足應發＝實領＋扣款＋另已發暫支薪。任何待確認細項或差額都會顯示核對提示。公司公提退休金獨立列示。

月份多筆給付會合併；未登錄月份以空隙呈現，不計作零收入。備份資料格式及 IndexedDB 結構維持 V1.0 相容。

## 測試

`npm test` 驗證虛構示範紀錄、收入與現金流圖表加總、月份缺口、同月多筆薪資、篩選及備份相容性。Actions 會在部署前執行核心測試與建置。

`npm run test:browser` 另以 Chrome 真正執行虛構薪資表格 OCR、金額欄位辨識、數字轉換及表單值自檢，並測試線上與離線辨識引擎、圖表、手機尺寸、安裝指引和離線重新開啟。這些瀏覽器測試不取代實際 Android 主畫面 App 驗收。

## OCR 候選版驗收

此版以獨立 build ID 隔離程式，OCR 模型按內容雜湊分開快取並逐一驗證。辨識失敗、取消或背景暫停時，兩張原圖與候選草稿會暫存在本機；暫存不進入正式歷史紀錄或備份。使用「資料與設定 → OCR 自檢與資源修復」可測試本機引擎、準備下載表格或通用模型、重新檢查快取，並複製不含金額、圖片、檔名及 OCR 原文的診斷摘要。

公開網站和自動測試僅使用程式產生的虛構圖片。實際薪資單不得上傳至 GitHub、Actions 或第三方 OCR 服務。此候選版需在 Android Chrome 主畫面 App 完成線上、離線、重開及三次重複辨識驗收後，才能標記修復完成。

## 手機安裝

在手機系統瀏覽器開啟 Pages 網址後，首頁的「安裝到手機」會顯示對應步驟。Android Chrome 若提供安裝視窗，可由按鈕啟動；若沒有，請使用 Chrome 選單的「安裝應用程式」或「新增至主畫面」。iPhone/iPad 請在 Safari 點「分享」→「加入主畫面」。LINE 等 App 內建瀏覽器請先改用 Safari 或 Chrome。

只有從主畫面以 App 模式開啟時，頁面才會顯示「正在使用 App 模式」。首次開啟時，請保持網路連線直到離線資源狀態顯示「可離線使用」。薪資資料仍留在原本瀏覽器的 IndexedDB；換裝置、換瀏覽器或更換開啟方式時，請使用「資料與設定」中的備份與還原。
